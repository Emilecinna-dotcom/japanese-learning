# Japanese Learning

Site pour apprendre le japonais depuis le français — kana, kanji, vocabulaire, grammaire et flashcards.

🔗 **Live** → [japanese-learning-five.vercel.app](https://japanese-learning-five.vercel.app)

## Fonctionnalités

- Hiragana & Katakana avec tableaux interactifs
- Kanji par niveaux JLPT
- Vocabulaire thématique avec audio
- Grammaire essentielle avec exemples
- Système de flashcards (répétition espacée)

## Stack

- React + TypeScript + Vite
- shadcn/ui + Tailwind CSS
- Déployé sur Vercel

## Lancer en local

```bash
npm install
npm run dev
```
