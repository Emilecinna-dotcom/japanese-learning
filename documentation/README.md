# Documentation — Apprendre le Japonais

Site pour apprendre le japonais depuis le français (socle JLPT N5) : kana, kanji, vocabulaire, grammaire, flashcards à répétition espacée, progression.

**Chemin :** `~/Projets web/japanese-learning`
**En ligne :** https://japanese-learning-five.vercel.app
**Stack :** Vite · React 19 · TypeScript · shadcn/ui · Tailwind CSS 4 · react-router-dom · Vercel
